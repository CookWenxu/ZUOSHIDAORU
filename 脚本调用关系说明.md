# 债券交易记录生成系统 - 脚本调用关系说明

## 项目结构

```
做市导入/
├── 脚本/
│   ├── run_all.py                    # 一键运行主脚本
│   ├── clean_test_input.py           # 输入清洗脚本
```

## 脚本详细说明

### 1. run_all.py - 一键运行主脚本

**调用方式：**
```bash
python 脚本/run_all.py
```

**调用流程：**
```python
步骤 1: subprocess.run(["python", "clean_test_input.py"])
        ↓
步骤 2: subprocess.run(["python", "test_deepseek_v4.py"])
        ↓
步骤 3: 解析 TXT 结果 → 导出 CSV
        ↓
步骤 4: 使用 pandas 转换为 Excel
```

**输入文件：**
- `输出样本/测试输入.txt`

**输出文件：**
- `输出样本/测试输入_cleaned.txt`
- `输出样本/测试结果_deepseek_v4.txt`
- `输出样本/测试结果_deepseek_v4.csv`
- `输出样本/测试结果_deepseek_v4.xlsx`
- `输出样本/token_stats.json`

---

### 2. clean_test_input.py - 输入清洗脚本

**调用方式：**
```bash
python 脚本/clean_test_input.py
```

**主要功能：**
1. **删除括号内容**
   - 移除中文括号 `（）` 和英文括号 `()` 及其中的内容
   - 清理多余空格

2. **对手方名称标准化**
   - 使用 `match_counterparty()` 函数进行模糊匹配
   - 将简称/别名转换为标准名称

3. **银行名称清洗**
   - 将"农商行"自动替换为"农商银行"
   - 统计替换次数

**调用关系：**
```python
clean_test_input.py
    ↓ 导入
counterparty_dict.py
    ↓ 调用 match_counterparty()
标准化对手方名称
    ↓ 调用 clean_bank_names()
银行名称清洗（农商行→农商银行）
```

**输入文件：**
- `输出样本/测试输入.txt`

**输出文件：**
- `输出样本/测试输入_cleaned.txt`

---

### 3. test_deepseek_v4.py - DeepSeek API 调用脚本

**调用方式：**
```bash
python 脚本/test_deepseek_v4.py
```

**主要功能：**
1. **读取输入数据**
   - 优先使用清洗后的文件（`测试输入_cleaned.txt`）
   - 如果没有则使用原始文件（`测试输入.txt`）

2. **调用 DeepSeek API**
   - 使用 DeepSeek-V4-Flash 模型
   - 生成结构化交易记录

3. **输出结果**
   - TXT 格式交易记录
   - Token 用量统计

**输入文件：**
- `输出样本/测试输入_cleaned.txt`（优先）
- `输出样本/测试输入.txt`（备选）

**输出文件：**
- `输出样本/测试结果_deepseek_v4.txt`
- `输出样本/token_stats.json`

**注意：**
- 数据清洗功能已移至 `clean_test_input.py`
- `test_deepseek_v4.py` 直接读取清洗后的文件

## 完整工作流程

### 方式一：一键运行（推荐）

```bash
python 脚本/run_all.py
```

**执行步骤：**
1. ✅ 调用 `clean_test_input.py` 清洗输入
2. ✅ 调用 `test_deepseek_v4.py` 生成交易记录
3. ✅ 自动解析 TXT 结果
4. ✅ 导出 CSV 格式
5. ✅ 转换为 Excel 格式

**优点：**
- 一键完成所有步骤
- 自动处理依赖关系
- 显示完整统计信息

---

### 方式二：分步执行

```bash
# 步骤 1: 构建对手方字典（首次使用或更新字典时）
python 脚本/build_counterparty_dict.py

# 步骤 2: 测试对手方匹配（可选，用于验证字典）
python 脚本/test_counterparty_match.py

# 步骤 3: 清洗输入数据
python 脚本/clean_test_input.py

# 步骤 4: 运行 DeepSeek 测试
python 脚本/test_deepseek_v4.py

# 步骤 5: 手动导出 CSV 和 Excel（run_all.py 已包含此功能）
```

## 常见使用场景

### 场景一：日常使用（一键运行）

```bash
python 脚本/run_all.py
```
适用于：每天都要处理新的交易数据

---

### 场景二：只更新交易记录

```bash
python 脚本/test_deepseek_v4.py
```
适用于：输入数据已经清洗过，只需要重新生成交易记录

---

### 场景三：更新对手方字典

```bash
# 1. 重新构建字典
python 脚本/build_counterparty_dict.py

# 2. 测试字典准确性
python 脚本/test_counterparty_match.py

# 3. 重新清洗输入
python 脚本/clean_test_input.py

# 4. 重新生成交易记录
python 脚本/test_deepseek_v4.py
```
适用于：积累了新的交易数据，需要更新对手方名称映射关系

---

### 场景四：调试和测试

```bash
# 测试对手方匹配
python 脚本/test_counterparty_match.py

# 测试清洗功能
python 脚本/test_clean_with_matching.py
```
适用于：验证字典配置是否正确，清洗功能是否正常
